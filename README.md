# Text Analysis

A beginner-level Python project that analyzes a given text and calculates basic text statistics.

## Objective

To analyze a given text and calculate:

- Number of words
- Number of characters
- Number of vowels
- Repeated words

## Technologies Used

- Python 3
- Jupyter Notebook

## Python Functions and Concepts Used

- `split()` – to separate the text into words
- `len()` – to count words and characters
- `for` loop – to process each character and word
- `if` condition – to identify vowels and repeated words
- `Counter` – to count the frequency of words
- `lower()` – to convert text to lowercase
- `strip()` – to remove punctuation from words

## Explanation

The given paragraph was analyzed using Python to identify basic text statistics.

The total number of words and characters was calculated using `split()` and `len()`.

The number of vowels was counted by checking each character in the text.

Repeated words were identified using Python's `Counter` and displayed along with their frequencies.

This analysis demonstrates basic text processing techniques using Python.

## How to Run

1. Open the `Text_Analysis.ipynb` file in VS Code or Jupyter Notebook.
2. Select the Python kernel.
3. Run the notebook cells from top to bottom.
4. View the calculated text analysis results.
